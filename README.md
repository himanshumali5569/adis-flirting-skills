# 💕 aadiiii - Adi's Flirting Skills (Website Prototype)

A modern, responsive romantic UI designed exactly based on your reference image.

## ✨ Features Included
- **Exact Visual Aesthetics**:
  - Soft romantic pink-to-magenta gradients matching the design.
  - Custom outline heart icons and typography using Google Fonts (*Plus Jakarta Sans*).
  - Exact hero section copy:
    - `♡ ♡ ♡`
    - `Welcome to:`
    - `Adi's Flirting Skills`
    - `Where charm meets heart, and every glance is an invitation`
  - Two stylish pill CTA buttons: `♡ Explore Skills` and `View Gallery`.
- **"A Gallery of Love"**:
  - Three beautifully styled pastel pink cards with crisp white borders and subtle drop shadows.
  - Interactive click burst animations and toasts.
- **Skills Section (Prototype Ready)**:
  - Left empty as requested, with a placeholder card ready to receive your custom skills whenever you provide them!
- **Mobile Responsive**:
  - Responsive hamburger navigation menu on small screens.
  - Responsive font scaling (`clamp()`).
  - Cards stack seamlessly into single-column on mobile devices.
- **No Login / Clutter**:
  - Clean, distraction-free landing page experience.

## 🚀 How to Open
1. Simply double-click `index.html` in your file explorer to open it directly in your web browser (Chrome, Edge, Firefox, Safari).
2. Or run a local development server using Python:
   ```bash
   python -m http.server 8000
   ```
   and visit `http://localhost:8000`.
